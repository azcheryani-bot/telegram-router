# Telegram Router Bot

مسیریاب تلگرام به بله / روبیکا / ایتا — همان نسخه‌ای که روی Hugging Face Space
اجرا می‌شد، بدون سرور Xray و بدون ربات بله اسیستنت.

- `telegram_router.py` — فورواردر تلگرام (Telethon) با هوش مصنوعی جمینی
- اجرا با GitHub Actions: هر ۵ ساعت در دقیقه ۵۸ UTC ری‌استارت می‌شود
  (concurrency باعث می‌شود اجرای قبلی با شروع اجرای جدید متوقف شود).
- همگام‌سازی با دیتابیس در ابتدا و انتهای اجرا، دقیقاً مثل نسخه هاگینگ‌فیس
  در خود کد هست (`init_router_db` و بارگذاری مسیرها/ادمین‌ها/وضعیت‌ها در رم
  در شروع، و `flush_all_to_db` بعد از `custom_idle` و با `atexit` در پایان).

توکن‌ها، سشن تلگرام و آدرس دیتابیس در GitHub Actions Secrets ذخیره می‌شوند
و در کد نیستند.
